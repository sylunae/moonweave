织月制谱（Moonweave）的首个公开 Alpha，面向 Windows x64 玩家和谱师。

### 第一次游玩

1. 下载下方的 `Moonweave-0.1.0-alpha.1-Setup.exe`，运行安装向导并打开「织月制谱」。
2. 下载[示例谱面 Rrhar'il](https://raw.githubusercontent.com/sylunae/moonweave/v0.1.0-alpha.1/public/tests/Rrhar%27il.mwchart)。在「我的谱面」点击「导入谱面」，选择下载的 `.mwchart` 文件。
3. 在编辑器点击「谱面试玩」→「从头开始」，按空格开始，跟随四条轨道上的音符演奏。

### 本版内容

- 支持四轨下落式试玩、单点、长按和红区模式。想先熟悉谱面，可以在试玩开始前开启「自动演奏」。
- 可以导入自己的音乐，在编辑器中调整 BPM、偏移与变速，放置音符，再导出谱面包分享。

遇到问题，欢迎到 [GitHub Issues](https://github.com/sylunae/moonweave/issues) 反馈。请附上 Windows 版本、谱面名称和复现步骤。
