* 字体不要有小于10px的，且标准字体大小应该至少12px及以上。、
* 用户偏好Flex布局优先，除非必要否则不要用Grid。
* 用户说“做demo前端”的时候，请不要为每个页面做单独的类单独的样式，请按照高一致性的标准做新的页面。
* 保留现有品牌视觉；主题 token 统一在 `src/styles.css` 管理。
* UI 优先复用现有组件库，禁止重复造轮子，交互也禁止使用浏览器原生。
* 不要添加多余的解释性文字，例如“点击复制，即可粘贴”这类，UI引导 > 文字引导。
* 不要使用模板化UI（虽然我说了也没什么用），而是根据项目的设计风格做创造，例如GPT就很喜欢用border-block来包裹信息层级，千篇一律毫无设计感可言。

# 主页面固定视口硬约束
- 大厅、创作者中心、个人资料等产品主页面必须使用 `AppScreen` 作为页面根节点，根节点占满内容区且不得产生整页滚动。
- 页面主体采用固定工作区、分栏、标签页或舞台式切换；禁止用 Hero、卡片瀑布流和纵向堆叠模块组成网页式长页面。
- 只有列表、表格、详情正文等明确区域可以滚动，并使用 `ScrollRegion` 或 `data-scroll-region` 显式标记；移动端也不得退化为整页纵向滚动。
- 上述页面按“游戏内菜单”设计，不按网站、管理后台或 SaaS Dashboard 设计：大厅使用封面选曲 Grid 与覆盖式详情；创作者中心使用作品槽位与发布终端；个人资料使用玩家卡、战绩和收藏陈列。
- 禁止在创作者中心使用 KPI 指标卡、数据看板或后台管理表格作为主界面；禁止在大厅使用营销 Hero、资讯流或左侧列表加右侧详情的后台布局。
- 修改上述页面后必须执行 `npm run check:ui-contract`；该检查失败时不得交付。
