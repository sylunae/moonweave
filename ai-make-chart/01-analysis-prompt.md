# 可选：MIDI 结构分析提示词

请实际解析附件 MIDI，为 4K 制谱输出简洁的 Markdown 结构报告。默认无需分析 WAV，也不要把这份报告作为后续制谱的必经前置步骤；资料足够时可以直接使用 `02-chart-prompt.md` 制谱。

如果不能解析 MIDI，请明确说明，不要按文件名猜音轨、BPM 或音符。

报告包括：

1. MIDI 格式、PPQ 或 SMPTE 时间制、音轨/通道、program、鼓通道、tempo map、拍号、末个事件时间。没有 tempo 事件时明确区分 MIDI 默认速度与显式速度。SMPTE 必须按其时间制转换，不套用 PPQ 公式。
2. 各声部的音域、音符数、节奏特征、主旋律/低音/伴奏/鼓组候选及依据；音轨名称和 program 只是线索，不等于真实音色。
3. 音符起止：按轨道/通道/音高配对 note-on/note-off，velocity=0 的 note-on 按 note-off 处理，说明重叠同音、缺失 note-off 和 CC64 延音踏板的处理。区分键释放与延音，不把全部 MIDI 时值机械映射成长条。
4. 段落、动机、重复/变奏、强弱层次，以及适合 4K 的骨架、旋律叠加和长条候选。
5. 直接使用用户提供的 MIDI，不询问是否原版或与音频一致。首次以 MIDI tick 0 为时间原点，修改时沿用旧 chart.json 的基准；不要求提供音频或额外锚点。
6. 自行记录解析中采用的合理处理方式，不把可选信息缺失转化为前置确认。

所有时间注明时间原点和单位。一拍为四分音符；八分音符 0.5 拍，十六分音符 0.25 拍。不要默认 4/4，也不以未定义的小节编号作为唯一位置。
