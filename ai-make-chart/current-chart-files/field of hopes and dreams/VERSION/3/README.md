下表使用四分音符拍坐标；一拍 480ms。

| 区间 | 第三版安排 |
| --- | --- |
| 0–16、16–32 | 两组不同材料分别原样复现，0–8 对应 8–16，16–24 对应 24–32。 |
| 32–64 | 四个八拍短句采用 A、A、镜像 A、镜像 A 的共同核心；保留原本存在的装饰音与最后两拍过门。48 拍短句比第一句多三个真实采音起点，27 个共同核心音符全部镜像对应。长条时值仍跟随原句。 |
| 64–96 | 32–64 的整句镜像，音符头、长条形状和时值均对应。 |
| 128–160 | 裸露旋律采用固定的左右手应答，共同骨架延续，换音和句尾保留自身变化。 |
| 160–188 | 重排快速旋律与和声同押；160–164、176–180 的密集起点最多双押，保留起点节奏。160–166 与 176–182 完整镜像对应。 |

共同核心先预留真实装饰音所需的手指空间，再复用到重复段，避免第三、第四个短句因为局部填充而整句重新分轨。没有使用随机分轨。
