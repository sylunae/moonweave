# music.wav：音色、乐句与情绪的第二次分析

本次重新处理原始 WAV，增加本地音频事件模型和乐句相似性比较。旧报告保留为信号测量参考。本报告中的乐器名称是候选，情绪描述是基于编配变化的解释，均非直接听辨结论。

## 方法、证据与限制

- 文件：`music.wav`，48,000 Hz，双声道，16-bit PCM，7,934,538 帧，165,302.875 ms。SHA-256 与第一版记录一致：`53bfb59083b85eb354fc2e13916f0b3f94ff3af8350b5ffe5f9f4ae2d9c83396`。没有改动原音频。
- 使用 YAMNet 的 Qualcomm float ONNX 版本，在本地 CPU 推理。分析工作副本为 16 kHz 单声道；每窗约 0.96 秒、步长 0.48 秒，输出音乐、乐器、风格和情绪相关候选标签。
- 按模型参考实现计算 log-mel 输入；模型原始输出按 logits 经 sigmoid 转换，再统计各窗口及各段分数。分数不是经本曲校准的概率，不应解释为“有多少百分比确定是某件乐器”。不同标签也不互斥。
- 另以谐波/瞬态掩膜抑制部分攻击成分，检查持续成分的标签变化。这只是诊断性处理，没有分离出独立的小提琴、钢琴或鼓轨；处理本身可能改变音色并诱发误判。
- 本次仍未直接听辨音频。用户已指出音乐中有明显主旋律、鼓点和提琴段，这是独立的用户试听证据；模型的弓弦候选与之相容，不能将两者写成模型独立确认了全部提琴段。
- 模型对“音乐”的识别较稳定，对具体乐器与风格的分数普遍较低。可以给出值得试听验证的候选及位置，不能给出确定配器表、录音方式或情绪事实。

模型说明：[TensorFlow YAMNet](https://github.com/tensorflow/models/blob/master/research/audioset/yamnet/README.md)。模型来源及预处理参考：[Qualcomm YAMNet 示例](https://github.com/qualcomm/qai-appbuilder/tree/main/samples/models/audio/audio_classification/yamnet)。完整本地推理统计见 `music-analysis-v2-evidence.json`。

## 1. 可能的乐器与声部

### 键盘类：钢琴、电钢琴或类似敲击包络的采样音色

**候选置信度：中低；尾段的键盘家族判断比具体“原声钢琴”更稳妥。**

96.03–99.87 秒短回落及 145.95 秒以后的尾段，键盘/钢琴标签持续进入候选前列。原混音中 Piano 的段均分分别约 0.074 和 0.072；以 96.48 秒为中心的窗口约 0.339，96.96 秒约 0.310。尾段抑制部分瞬态后，Piano 段均分约 0.116。

这支持优先寻找承担独立音头、短音旋律或和声分解的键盘音色。不能由此确定使用真实钢琴、电钢琴还是具有相似包络的音源。尾段同时出现拨弦类候选，说明部分短音的来源存在混淆，不宜列成“已经确认另有吉他”。

### 弓弦类：提琴、弦乐采样或具有相近持续音色的合成声部

**候选置信度：中低；用户已指出存在提琴段，但具体种类及全部出现位置未确认。**

61.47–76.83 秒是本次最值得检查的区间。原混音中 Violin 与 Bowed string 的段均分均约 0.049；以 67.68、75.84 秒为中心的窗口，Violin 分数约 0.250、0.279。持续成分诊断中，弓弦家族的段均分约 0.103，小提琴约 0.096。

同时，持续成分也给出木管、口琴、单簧管和手风琴等候选。这表明模型对该音色的归属并不稳定。可记录为“提琴/弓弦类持续旋律候选”，不能据此追加一整套真实木管或簧片乐器。

编排上的重点是：鼓与低频撤出之后，持续旋律可能成为叙述主体。这一段应检查旋律的延续、换音与呼吸，而非只写作“密度降低”。目前仍没有可靠的逐音长条终点。

### 鼓组与低音骨架

**鼓点存在有用户试听支持；模型对具体鼓件的识别较弱。**

低频进入、撤出与周期性攻击支持稳定的节奏骨架。92.19–96.03 秒及 130.59–145.95 秒的原混音中，Drum、Percussion、Drum kit 等进入相对靠前的候选，但分数低，不能依靠本次模型列出确定的底鼓、军鼓和踩镲谱。

较重的低频攻击也可能包含低音声部或多声部齐奏。因此需要分别识别重鼓与旋律重音，不能让音量或单一频带决定同押数量。电贝斯、合成贝斯与原声低音提琴目前无法区分。

### 电子/合成键盘与其他音色

**候选置信度：低。**

持续成分中的部分主体段会出现 Organ、Electronic organ、Electric piano 等标签；开头有键盘、木管样音色的混淆。可以把电子键盘或采样音色作为检查方向，不能确定具体合成器类型或音源。

开头原混音还被标为 Ringtone/Telephone，而谐波处理后这类分数明显下降。这是模型对简单重复攻击音型的混淆线索，不能据此断言音乐中有电话铃声，也不能单凭这个结果确定为芯片音乐。

没有获得明确的人声识别证据；这不足以证明全曲绝对无人声采样。

## 2. 风格与整体情感：工作假设

**当前可用的宽泛描述：具有稳定律动、键盘与持续旋律交织的器乐游戏配乐；可能使用电子或采样音色。** 风格标签的模型分数低，电子音源的判断也较弱，具体流派待试听。

原混音的主体及再现段中，Video game music、Soundtrack music 和 Exciting music 多次出现在候选前列。Jazz、Swing、Country 等也有响应，但缺乏独立证据，不能将候选排名直接拼成“爵士乡村摇摆风”。目前也未确认摇摆比例、调式、和声走向或调性。

可供试听检验的情绪线是：**短小重复动机建立期待 → 鼓与低音加入形成轻快推进 → 节奏层让位，持续旋律获得更抒情的空间 → 节奏回归、动机再现带来重新出发感 → 键盘类音色接管尾段，转向较私密的收束。**

“轻快、期待、抒情、重新出发、私密”均为解释性假设，置信度低至中低。依据除了强弱，还有声部显露、攻击与延续的对比、动机复现及尾段音色变化。不能把它们写成作曲者意图，也不能据此确定剧情或“悲伤/希望”的唯一含义。

## 4. 重复关系：新增的实际比较

本次比较了每对起点之后 15,000 ms 的 log-mel 时间轨迹，并对各频带去除时间均值，以减少只比较平均音量或平均音色的问题。下列相关系数是本方法中的相似度，不是“旋律相同概率”，也不能证明逐音或和弦相同。

| 比较的原音频起点 ms | 相关系数 | 可以支持的结论 |
| --- | ---: | --- |
| 15390 与 30750 | 0.897 | 动态音色与节奏轨迹高度相似，优先核对为近似原样复现；适合复用或镜像共同谱型。 |
| 46110 与 130590 | 0.714 | 有较明显的材料对应，适合检查变奏再现，并保留共同节奏/旋律骨架。 |
| 15390 与 99870 | 0.468 | 有部分共同材料，但变化不可忽略，不能直接整段照搬。 |
| 30750 与 115230 | 0.471 | 同上，应逐句检查再现中新增或改变的声部。 |
| 61470 与 145950 | 0.131 | 同样低频较少，不代表是相同乐句；不应只因两段都“轻”就复制同一写法。 |

这些结果比“频谱平均值类似”更接近动态乐句比较，但仍没有独立追踪主旋律音高。它们可以指导后续分析与编排，不能直接当作音符清单。

## 5. 对后续制谱的具体意义

1. 先在约 66,700–69,200 ms、75,300–76,800 ms 检查用户指出的提琴类线条，逐个确认延音、换音与断句。以上范围由模型窗口定位，仅供试听，不是长条起止。
2. 在约 96,000–97,500 ms 与 145,950–159,390 ms 检查键盘旋律和短音。不能把所有键盘音做成长条，也不能因为没有鼓就整段稀疏化。
3. 主体段分别提取鼓与旋律节奏；重鼓、普通鼓点、旋律重音要分层。模型未可靠区分各件鼓，仍需补充声部级分析。
4. 优先建立 15,390 ms 起的代表乐句，再检查 30,750 ms 的对应，决定原样复用或镜像；46,110 与 130,590 ms 的变奏同样应成对核对。
5. 情绪变化用声部配置表达：持续旋律显露时考虑有依据的长条；节奏回归时叠加鼓点；尾声跟随键盘音型收束。不能仅以“能量高就加同押”处理全曲。
